\# Cognifyz Technologies – Machine Learning Internship



\## Project: Restaurant Rating Prediction



\### 1. About the Project

This project focuses on predicting restaurant ratings using machine learning algorithms and the Zomato restaurant dataset.



\### 2. Objective

To analyze restaurant data, identify important features, and develop machine learning models to predict restaurant ratings.



\### 3. Dataset Information

\- Dataset: Zomato Restaurant Dataset

\- Total Records: 9,551

\- Total Features: 21

\- File Format: CSV



\### 4. Technologies Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Scikit-learn

\- Joblib

\- Jupyter Notebook



\### 5. Project Workflow

1\. Data collection and loading

2\. Data cleaning and preprocessing

3\. Exploratory Data Analysis (EDA)

4\. Feature selection

5\. Model training

6\. Model evaluation

7\. Best model selection

8\. Model saving



\### 6. Machine Learning Algorithms

\- Linear Regression

\- Decision Tree Regressor

\- Random Forest Regressor



\### 7. Model Performance



| Algorithm | R² Score |

|---|---:|

| Linear Regression | 0.4554 |

| Decision Tree | 0.5439 |

| Random Forest | 0.6101 |



Best Performing Model: Random Forest Regressor



\### 8. Evaluation Metrics

\- Mean Absolute Error (MAE)

\- Mean Squared Error (MSE)

\- Root Mean Squared Error (RMSE)

\- R² Score
